# HT Mod — Minecraft 1.21.1

Добавляет чёрный блок HT и команду `/ht`.

Этот вариант специально сделан так, чтобы в корне репозитория были только обычные видимые файлы. Исходник и ресурсы создаются Gradle автоматически во время сборки.

Для сборки через GitHub Actions создай workflow через Actions → Java with Gradle и используй команду `gradle build --no-daemon`.
